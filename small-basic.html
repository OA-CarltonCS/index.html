1. Commanding the Turtle Engine

In Small Basic, we can direct a virtual Turtle to construct complex graphics on an output canvas. Imagine it as an independent robot keeping a felt pen pushed firmly down to the paper as it follows instructions.

Turtle.Speed = 8
Turtle.Move(150)
Turtle.Turn(90)

Speed Variables

Adjusts drawing velocities. The range runs exclusively from values 1 (slowest rendering) through to 10 (instant execution).

Vector Manipulation

Executing Move(150) projects the module forward across 150 spatial line steps. Turn(90) rotates your object directly right.

2. Control Loops (Iteration)

Duplicating multiple lines of similar commands is inefficient. We apply a For Loop structure whenever code blocks require controlled automation loops.

For counter = 1 To 4
  Turtle.Move(100)
  Turtle.Turn(90)
EndFor

How it works: The variable tracks operations starting at index 1. Upon reaching the EndFor terminal boundary line, the runtime engine increments calculations seamlessly, rendering an operational 4-sided geometric square automatically.
